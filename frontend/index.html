    Plages de transfert et vitesse

    Envois et restaurations 1fichier, copies vers disque : un élément ne démarre que pendant une plage activée, la file attend hors plage. Un envoi 1fichier déjà commencé va jusqu'au bout ; une copie disque est suspendue hors plage et reprise à la plage suivante. Une seule copie à la fois par disque. La vitesse de la plage active s'applique (0 = illimité). Heures du serveur : variable TZ (ex. Europe/Paris). Sans plage activée, les transferts sont en pause. Priorité par défaut : normal (réglable sur chaque tâche).

    1fichier (sauvegarde premium)

    Clé API dans ton compte 1fichier (section API). Chaque film, série ou dossier d'ebooks part en archive 7z chiffrée (AES-256) dans son dossier : tmdb-<id> pour un film, tmdb-tv-<id> pour une série, ebook-<empreinte> pour un ebook, avec son propre mot de passe. Ces mots de passe sont dans le fichier d'index du volume de données : sauvegarde ce volume, sans lui les archives ne s'ouvrent plus.

    Restauration : dossiers où remettre les éléments récupérés depuis 1fichier (chemins absolus, montés dans le conteneur). Vide = pas de dossier par défaut.

    Copie de l'index : l'index contient le mot de passe de chaque archive. Il est sauvegardé automatiquement (copies dans 1fichier-index.json.backups/, à côté de l'index). Pour une copie hors du serveur, exporte-le ci-dessous : archive 7z chiffrée, téléchargée dans ton navigateur. La phrase de passe n'est enregistrée nulle part : note-la.

    Contrôles automatiques : chaque nuit, tous les liens sont vérifiés, et un élément (archive de 20 Go au plus) est téléchargé et testé une fois par mois. L'heure se règle avec la variable ONEFICHIER_CHECK_HOUR (3 par défaut).

    Comportement
    Protection (lecture seule, réglée dans le fichier .env)

    Médias adultes : masqués.

    Le code est vérifié par le serveur et enregistré sous forme d'empreinte, jamais affiché. Tant qu'un navigateur n'a pas saisi le code, les médias adultes restent masqués partout, y compris dans les listes, les fiches et les actions. Le déverrouillage vaut pour ce navigateur, jusqu'à sa fermeture (24 h au plus).
